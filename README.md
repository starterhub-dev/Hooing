# FAKA24 Decoder Lab

一个静态、本地优先的卡密字段整理与 TOTP 演示网页。

## 输入规则

以空格或换行分段：
- 第 1 段：账号
- 第 2 段：密码
- 第 3 段至末尾：2FA Base32 密钥（移除密钥分组空格后用于计算）

## 功能
- 字段整理与复制
- 使用浏览器 Web Crypto API 本地计算 TOTP（HMAC-SHA1、30 秒周期、6 位数字）
- 缺少字段或密钥格式错误时显示提示
- 不验证账号或密码是否有效

## 隐私与安全
- 静态网页，不包含后端请求或分析脚本。
- 输入内容不会主动上传；不要在共享设备上处理真实凭据。
- 仅用于你有权访问的账号。不要公开分享密码或 2FA 密钥。
- TOTP 结果依赖设备系统时间；如果目标站点使用不同算法、位数或周期，结果可能不匹配。
- 建议通过 HTTPS 或 localhost 运行，以确保浏览器 Web Crypto API 可用。

## 本地预览
直接用浏览器打开 `index.html`。如 Web Crypto 不可用，可在本地启动开发服务器，例如 `python -m http.server 8000`，然后访问 `http://localhost:8000`。
