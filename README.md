# ORBIT · 宇宙漫游

一个使用原生 HTML、CSS、JavaScript 和 Three.js 构建的 3D 宇宙探索原型。

## 当前原型

- 程序化生成太阳、行星和月球的表面纹理
- 星空背景与 3D 球体展示
- 行星选择栏与天体信息
- 鼠标/触控拖动旋转、滚轮缩放
- 自动旋转与简单合成音效

## 当前已知待完善项

- 顶部“近地轨道 / 太阳系 / 银河系”按钮目前只切换选中样式，还没有切换对应场景
- 近地轨道、行星轨道和天体之间的空间关系尚未建模
- 移动端需要进一步测试触控、缩放、布局和性能
- 纹理目前由程序随机生成，尚非真实天文影像

## 开发原则

1. 先保留原型，再小步迭代。
2. 每次修改都保持可运行，并留下清晰的 Git 记录。
3. 先完善交互和移动端体验，再扩展场景与天体数据。
4. 暂不引入不必要的框架或构建工具。

## 本地运行

直接用现代浏览器打开 `index.html`。页面通过 CDN 加载 Three.js，因此运行时需要网络连接。

## 开发分支

当前原型先存放在 `orbit/initial-import` 分支中；确认运行正常后再考虑合并到 `main`。
